<h3>Описание веток</h3>

<ul>
<li>main - здесь только стабильные версии приложения (для демо), каждый коммит имеет свой тег.</li>
<li>develop - основная ветка разработки, в нее собираются все фичи.</li>
<li>feature - ветки для фич. У каждой фичи должна быть своя ветка.</li>
</ul>

<h3>Порядок работы над фичами</h3>

<ol>
<li>От develop бранчим новую ветку, название должно иметь вид

> back/front-номер описание 

Например,

> back-1 add ServiceController

</li>
<li>Работаем над фичей, не забываем про тесты. Все коммиты льем в созданную ветку.</li>
<li>Когда фича готова - делаем Merge Request в develop, указываем ревьюера, ждем аппрув. При необходимости исправляем ошибки.</li>
</ol>

<h3>Как сделать Merge Request</h3>
<p>В меню слева Code -> Compare revisions. В source указать ветку с фичей, в target - develop. </p>
