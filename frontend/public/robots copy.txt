## ProgressBar

### Подключение
```javascript
import { ProgressBar } from '@hh.ru/magritte-ui';
```

Для override подключения:
```javascript
import { ProgressBar } from '@hh.ru/magritte-ui-progress-bar';
```

**Описание:**
Компонент предназначен для отображения прогресса, процента загрузки, прохождения шагов.

### Типы ProgressBar

**SingleProgressBar**
* Задается пропом `progress` (текущий прогресс)
* Имеет опциональный проп `max` (значение по умолчанию 100)

**SegmentedProgressBar**
* Задается пропом `progress` (текущий прогресс)
* Имеет проп `segments` (общее количество сегментов)

### Кастомизация компонента

**Основные характеристики:**
* Компонент тянется на ширину контейнера
* Поддерживает кастомизацию через CSS-переменные

**CSS-переменные для кастомизации:**

| Свойство | Название CSS-переменной |
|----------|-------------------------|
| Отступы между сегментами | `--magritte-ui-progress-segments-margin-override` |
| Высота | `--magritte-ui-progress-height-override` |
| Цвет заполненной части | `--magritte-ui-progress-value-color-override` |
| Цвет фона | `--magritte-ui-progress-background-color-override` |

### Параметры компонента

| Параметр | Описание | Значение по умолчанию |
|----------|----------|-----------------------|
| `progress`* | Текущее значение прогресса | number |
| `style` | Стиль прогресс-бара | "accent", "positive", "special" |
| `aria-label` | String | - |
| `data-qa` | String | - |
| `max` | Максимальное значение прогресс-бара | number |
| `segments` | Общее количество сегментов | number |

*Примечание: параметр `progress` является обязательным*
